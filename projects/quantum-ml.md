This project explores small-scale quantum circuits combined with classical networks for hybrid learning experiments.

### Current Direction

- Build intuition for hybrid models through small, readable simulations.
- Compare classical baselines with simple circuit-based alternatives.
- Document useful observations instead of treating the work as a black box demo.
